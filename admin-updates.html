修改紀錄管理

像寫部落格一樣：新增、✏️ 編輯、🗑 刪除、💾 暫存、🚀 上線（網站「公開回覆」區塊的內容）。所有回覆預設都是暫存，按 🚀 才會公開。

🔑 第一次使用：設定 GitHub 權限（只存在這台裝置，不會公開）
  1. 登入 GitHub → 右上頭像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
  2. Repository access 選「Only select repositories」→ 只選 boa19950303-artale。
  3. Permissions → Repository permissions → Contents 設成 Read and write，其他都不要開。Expiration 建議 90 天。
  4. 產生後複製（只會顯示一次），貼到下面。

沒設定權限也能用：你可以編輯、暫存，按「複製 updates.txt」把文字貼給 Claude，由 Claude 上線。
